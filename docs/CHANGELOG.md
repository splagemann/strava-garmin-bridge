## [Initial Release]

### Added

#### Core Features
- Automatic sync of Strava activities from the last 7 days (polled every 5 minutes)
- Secure OAuth2 authentication for Strava
- Encrypted credential storage for Garmin Connect
- Smart activity filtering with regex pattern support
- Include/exclude filters based on activity title or type
- Sync history tracking with detailed logs
- Manual retry for failed synchronizations
- Automatic duplicate detection and skipping

#### Technical Implementation
- FastAPI backend with async support
- React + TypeScript + Vite frontend with Tailwind CSS
- PostgreSQL database for persistent storage
- Celery task queue with Redis for async processing
- Celery beat for scheduled polling
- FIT format conversion with proper activity type mapping
- Docker and Docker Compose deployment support
- Database migrations with Alembic

#### Security
- Fernet symmetric encryption for Garmin credentials
- OAuth2 flow for Strava (no password storage)
- Secure environment variable configuration
- Session management with secret keys

#### User Interface
- Dashboard with sync statistics

- Filter management interface

- Garmin credential configuration
